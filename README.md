# SuperPower 校内赛底盘控制代码 (Chassis C Board)

## 一、主要任务
本仓库为同济大学 SuperPower 战队 2027 赛季校内赛**底盘控制板**代码。
基于 RoboMaster C 型开发板，独立完成以下任务：
1. **底盘运动控制**：通过 DT7 遥控器控制 4 个 M3508 麦轮底盘完成前后、横向、旋转运动。
2. **安全失能逻辑**：右拨杆下档时，底盘全部电机断电无力，且通过 CAN 总线向云台板发送急停指令。
3. **自动直线行驶**：右拨杆上档时，底盘自主直线行驶 3.5 米，并带有平滑减速缓冲。
4. **功率控制**：建立电机功率预测模型，结合功率计反馈，将底盘功率限制在 80W 以内（符合 V2.1.0 规则手册 7.4.5 要求）。
5. **跨板通信（CAN 总线）**：通过 CAN1 发送心跳包（0x124）与急停帧（0x123），保障底盘与云台板的协同安全。

## 二、硬件平台
- **主控**：STM32F407IGH6（RoboMaster C 型开发板）
- **底盘电机**：RM3508 × 4 + C620 电调（CAN2 总线，ID 1~4）
- **遥控器**：DT7 + DR16（DBUS 接口 / USART3）
- **功率计**：CAN 标准帧 0x301（反馈电压、电流、实际功率）
- **通信接口**：CAN1（连接云台 C 板）、UART1（SerialPlot 调试输出）

## 三、软件架构
- **框架**：STM32 HAL 库 + FreeRTOS（CMSIS_V1）
- **构建**：CMake + ARM GCC
- **语言**：C++（业务逻辑）+ C（HAL 底层）
- **编辑器**：VSCode + CMake Tools

## 四、目录结构
- `applications/` — 任务层代码
  - `chassis_task.cpp` — 底盘核心任务（运动学、PID、功率控制、自动行驶、CAN1/CAN2 通信）
  - `uart_task.cpp` — 遥控器 DBUS 接收
  - `plotter_task.cpp` — 串口波形输出（仅输出目标功率与实际功率）

## 五、核心功能说明
### 1. 失能优先级与安全机制
- **右拨杆下档**：最高优先级，直接切断 4 个 M3508 电机输出，清空 PID 状态，并通过 CAN1 发送急停帧（0x123）通知云台板。
- **遥控器断线保护**：超过设定时间未收到 DBUS 数据，底盘自动失能，并同样发送急停帧。
- **心跳包机制**：底盘正常或失能时，均以 1ms 周期向 CAN1 发送心跳帧（0x124）。若云台板超过 100ms 未收到心跳，云台应自行切断动力。

### 2. 底盘运动学与双环/单环 PID
- 采用标准麦轮逆运动学解算，将车体期望速度（vx, vy, ω）解算为四个轮子的目标线速度，再转换为电机角速度。
- 速度环 PID 参数：Kp=0.8, Ki=0.02, max_out=16384（对应 20A 限幅）。左右侧电机方向已在代码中镜像修正。

### 3. 功率控制策略
- **预测模型**：`P_in = Σ(τ×ω) + K1×Στ² + K2×Σω² + K3`
- **限制算法**：预测功率超过（裁判上限-5W）时，通过解一元二次方程计算缩放系数 K，对目标电流进行等比例缩减。
- **闭环兜底**：接收功率计（CAN 0x301）的真实功率，若超过 80W，进一步降低 K 值。
- **串口输出**：通道 1 输出预测功率，通道 2 输出实际功率，供裁判验收。

### 4. 自动直线行驶（上档）
- 利用电机反馈的实时转速积分计算出行驶距离。
- 目标 3.5 米，当剩余距离小于 0.5 米时，目标速度随距离线性递减，实现平滑刹停。

## 六、操作注意事项
1. **安全第一**：拨杆下档为失能模式。每次上电或重新烧录程序后，必须先验证四个轮子处于无力状态，再将底盘放回地面。
2. **物理接线**：
   - 底盘 4 个 C620 电调串联接在 C 板 **CAN2** 接口。
   - C 板 **CAN1** 接口连接至云台板 CAN1。**CAN_H 接 CAN_H，CAN_L 接 CAN_L，GND 接 GND**。
   - **切勿将 C 板 CAN 接口的 5V 引脚接入任何电调**。
3. **调试限制**：底盘调试时务必使轮子离地；串口打印的预测功率曲线需与功率计反馈的实际功率曲线吻合后再上地跑车。
4. **终端电阻**：CAN 总线两端必须有且只有两个 120Ω 终端电阻（由首尾设备的拨码开关开启）。
